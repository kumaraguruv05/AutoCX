Algorithmic & Mathematical Analysis:
1. Target Log-Transformation: Car resale prices exhibit heavy positive skew 
   (y in [Rs 30,000, Rs 1,00,00,000]). TransformedTargetRegressor applies 
   z = ln(1+y) during training and reverses predictions via y_hat = exp(z_hat) - 1, 
   preventing negative valuation anomalies and compressing high-variance luxury outliers.
2. L2 Regularization Penalty: Ridge estimator minimizes penalized loss function:
   Loss_Ridge = SUM(y_i - w^T x_i)^2 + alpha * ||w||_2^2
   with regularizer alpha = 10.0, stabilizing collinear features.
3. Leakage-Free Median Anchoring: model_anchor_dict maps historical brand-model baseline 
   prices calculated exclusively over train_df, preserving zero-leakage test integrity 
   (R^2 = 0.7987, MAE = Rs 1,50,209.43).

from typing import Any, Dict, List
from pydantic import BaseModel

class ModelDetail(BaseModel):
    available: bool
    model_name: str
    algorithm: str
    version: str
    training_dataset: str
    training_samples: int
    test_samples: int
    validation_strategy: str
    metrics: Dict[str, Any]
    all_candidate_metrics: Dict[str, Any]
    feature_schema: Dict[str, Any]
    limitations: List[str]

class ModelsInfoResponse(BaseModel):
    car_resale_model: ModelDetail
    battery_soh_model: ModelDetail
    environment: str
--------------------------------------------------------------------------------

Operational Summary:
Defines immutable validation data structures for live model discovery, ensuring that the frontend 
cockpit automatically renders accurate R^2 scores, sample sizes, and algorithm definitions.
